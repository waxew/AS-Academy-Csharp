# اتصال به AS-Academy-Core

این ریپو Course Repository است و **هسته اپلیکیشن را دوباره پیاده‌سازی نمی‌کند**.

## از Core استفاده می‌شود
- Navigation و App Shell
- Design System و RTL
- Database/Room و migration framework
- Content Engine و Course importer
- Progress، Quiz، Exercise و Project Engine
- Search، Bookmark و Glossary Engine
- Profile/Drawer و Settings
- Update، Backup و Achievement
- Code Runner framework
- Course schema و validator

## مسئولیت این ریپو
- `course/manifest.json`
- محتوای درس‌های C#
- تمرین‌ها و آزمون‌ها
- پروژه‌ها و نمونه‌کدها
- واژه‌نامه
- Branding اختصاصی C#

هر تغییر عمومی باید ابتدا در `waxew/AS-Academy-Core` اعمال شود.
