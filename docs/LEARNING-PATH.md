# مسیر یادگیری

`مبانی → مقدماتی → پیشرفته → تخصصی`

هر درس از قالب ثابت AS Academy استفاده می‌کند:

`مفهوم → کاربرد → Syntax → مثال → تحلیل خط‌به‌خط → تمرین → پاسخ → خطاهای رایج → نکته حرفه‌ای → پروژه`

پیشنهاد مطالعه: درس را بخوانید، مثال را بدون copy/paste بازنویسی کنید، تمرین را حل کنید و فقط بعد از آن پاسخ مرجع را بررسی کنید.
