## قالب استاندارد هر درس

`توضیح مفهوم → کاربرد → Syntax → مثال ساده → مثال واقعی → توضیح مرحله‌به‌مرحله → تمرین → پاسخ تمرین → خطاهای رایج → نکات حرفه‌ای → پروژه`

## پروژه‌های عملی

مسیر پروژه‌ها از ماشین‌حساب، To-Do List و مدیریت فایل آغاز می‌شود و تا حسابداری، CRM، فروشگاه اینترنتی، REST API، سیستم Real-time، Clean Architecture، Microservices و برنامه‌های هوشمند ادامه دارد.

## سطوح AS Academy

`مبانی → مقدماتی → پیشرفته → تخصصی`

هدف این مخزن ایجاد یک مرجع آموزشی پروژه‌محور و قابل توسعه برای C# و .NET است.
